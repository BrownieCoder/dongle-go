# Security / 安全

This preview has no telemetry, automatic update service or network listener. Diagnosis is local. The only planned device writes are a qualified USB network-mode setting and its required soft restart; the factory USB backend currently rejects both.

Do not post private logs or SIM/device identifiers in public issues. Use GitHub private vulnerability reporting if it is enabled; otherwise open an issue describing only the affected component and request a private channel before sharing sensitive reproduction details.

中文：预览版无遥测、自动更新服务和网络监听。请勿在公开 issue 中粘贴私人日志、SIM 或设备标识。漏洞详情优先使用 GitHub 私密漏洞报告；若未启用，只公开组件名称并先约定私密沟通渠道。
