# 小白教程

简体中文 · [English](getting-started.md)

**先点击检查连接。配置需要匹配已启用的固件；当前版本提供只读诊断和操作演示。** 演示模式只用于体验界面：显示成功不会配置真实模块，也不能证明真实网络可用。

当前出厂 USB 通道只提供只读诊断，不配置、重置或重启模块，也不安装 Windows USB 驱动。没有兼容驱动时，先停留在诊断阶段，等待经过验证的操作流程。

## 1. 准备 SIM 卡和数据线

使用已开通流量的实体 SIM 卡。模块不通电时，按设备说明插卡。准备能传输数据的 USB 线；首次尝试建议直接连接电脑，暂时不用扩展坞。

## 2. 选好最后上网的设备

- **Mac：** 在 Mac 上配置，也在这台 Mac 上使用。
- **Windows：** 在 Windows 电脑上配置并使用。USB 驱动是否可用是兼容性验证的一部分，不要根据来路不明的教程安装未签名驱动。
- **USB-C iPad：** 先在 Windows 或 Mac 上配置，再把模块接到 iPad。iPadOS 兼容性和供电要单独验证。

## 3. 插入模块，检查是否支持

程序应先确认模块型号，再提供配置操作。USB 设备名称相似，不能证明型号兼容。如果识别不完整或型号不支持，请按诊断提示处理，不要为了继续操作而选一个不相关的串口设备。

## 4. 配置 USB 上网

预期主按钮为**一键开通上网**。操作过程中，模块可能短暂断开并重新连接，请保持数据线连接，不要同时运行其他模块管理工具。

**“配置已保存”和“已经联网”是两件事。** SIM 卡异常、信号弱、网络设置或供电不足，都可能让配置成功的模块暂时无法上网。

## 5. 在实际使用的设备上确认联网

电脑连着家里 Wi-Fi 时能打开网页，不能证明模块工作正常。需要确认系统出现 USB 网络连接，而且流量确实经过它。正式验收应断开其他网络，再验证蜂窝数据通信；这可能消耗你的套餐流量。

如果目标是 iPad，把配置后的模块接到 iPad，在“设置”中查看是否出现“以太网”。仅出现这个入口仍不等于能够联网。没有出现时，回到电脑诊断，不要在 iPad 上反复尝试不明配置命令。

## 6. 检查日常使用

准备长期使用前，分别试一下拔下再插、电脑重启、睡眠后唤醒。iPad 需要单独测试重新连接。长期使用需要这些日常场景都能稳定连接。

某一步失败时，请看[故障排查](troubleshooting.zh-CN.md)。公开版本需要经过验证的恢复方法，才能推荐给完全不懂技术的用户。
