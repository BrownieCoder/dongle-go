# 遇到问题怎么办

简体中文 · [English](troubleshooting.md)

当前程序为开发预览，已验证固件白名单为空。只有具体固件通过真机验收后，才会开放真实配置。演示模式不会改变这个限制。

| 看到的情况 | 下一步 |
| --- | --- |
| 无法访问出厂 USB 接口 | 确认程序包含 libusb 库，关闭其他管理工具。Windows 需要现有兼容驱动；不要为尝试预览而用 Zadig 替换驱动或关闭签名验证。此通道仍只能诊断。 |
| 没找到模块 | 直接连接电脑，换一根已确认能传数据的线，再试另一个 USB 接口。仅凭未检测到设备，无法判断是否为充电线。 |
| 型号或固件不支持 | 停止操作。不要修改设备标识或冒用其他型号绕过检查。反馈维护者要求的非敏感型号与固件信息即可。 |
| 串口被占用或无法访问 | 关闭其他模块管理工具，重新连接，再点“检查连接”。不要默认通过授予广泛管理员权限解决。 |
| 没有 SIM 或 SIM 被锁 | 先断电再检查插卡。PIN 锁定请通过运营商或支持的设备处理；反复输错 PIN 可能导致进一步锁卡。 |
| 配置成功，但不能上网 | 检查套餐是否开通、是否有剩余流量、信号和运营商设置。配置成功不等于联网成功。 |
| 网页能打开，但不确定是不是模块在上网 | 可能仍在使用 Wi-Fi 或其他网络。通过系统网络状态与真机验收流程，确认实际使用的连接。 |
| 配置时模块断开 | 改变 USB 模式后可能短暂重连。先看程序提示；超时后检查连接，不要连续重复点击配置。 |
| iPad 没出现“以太网” | 检查数据线、供电，并确认模块在配置电脑上可用。iPad 兼容性仍是实验性目标。 |
| 睡眠或重启后不能上网 | 这是需要解决的兼容问题，不能算验收通过。记录系统、固件版本和发生步骤，反馈时删除隐私标识。 |

## 恢复原配置

只有程序保存了当前模块可用的配置快照时，才能使用**恢复原配置**。不要使用其他模块的备份。存在恢复按钮，不代表你的固件恢复操作已经验证；公开发布前需要真机测试。无法恢复时，请停止并反馈，不要继续尝试其他教程里的 AT 指令。

## 如何反馈

请提供系统版本、程序版本、目标设备、失败步骤及界面错误信息。截图和日志中应删除电话号码、ICCID/IMSI、IMEI、短信、SIM PIN、密码和令牌。不要在公开 issue 中上传原始配置备份；需要时自行保留一份原始诊断证据。
